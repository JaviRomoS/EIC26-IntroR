Módulo 1
La interfaz de RStudio

R y RStudio: ¿cuál es la diferencia?

Módulo 1 · Interfaz

R

  • Un lenguaje de programación para analizar datos.
  • Es el que hace los cálculos.
  • Gratuito y de código abierto.

RStudio

  • Un entorno de trabajo para usar R.
  • Organiza el código, los datos, los gráficos y la ayuda.
  • Hay que instalar los dos: primero R, luego RStudio.


R es lo que usamos; RStudio es solo la interfaz.

Los cuatro paneles de RStudio

Módulo 1 · Interfaz

1 · Editor (script) Donde escribimos y guardamos el código. Es nuestro cuaderno de trabajo.

3 · Entorno (Environment) Muestra los objetos que hemos creado: bases de datos, vectores, resultados.

2 · Consola Donde R ejecuta el código y muestra los resultados.

4 · Archivos / Gráficos / Paquetes / Ayuda Navegar carpetas, ver gráficos, revisar paquetes instalados y leer la ayuda.

La consola

Módulo 1 · Interfaz

Podemos escribir código directamente en la consola y presionar Enter:

2 + 2
[1] 4
  • El símbolo > indica que R está listo para recibir una instrucción.
  • Si aparece +, R está esperando que terminemos la instrucción (falta cerrar un paréntesis o una comilla). Se sale con Esc.
  • El [1] indica que el resultado empieza en el primer elemento.

Lo que escribimos en la consola no queda guardado. Sirve para probar cosas rápidas, no para trabajar.

El script

Módulo 1 · Interfaz

Un script es un archivo de texto con extensión .R donde escribimos el código para poder guardarlo, corregirlo y volver a ejecutarlo.

  • Nuevo script: File → New File → R Script (Ctrl + Shift + N).
  • Ejecutar una línea o selección: Ctrl + Enter (en Mac: Cmd + Enter).
  • Ejecutar todo el script: Ctrl + Shift + Enter.
  • Todo lo que va después de # es un comentario: R no lo ejecuta.
# Esto es un comentario: sirve para explicar qué hace el código
3 * 5   # también se puede comentar al final de una línea
[1] 15

El script es la fuente de verdad de nuestro análisis: cualquier persona debería poder abrirlo y obtener los mismos resultados.

El entorno (Environment)

Módulo 1 · Interfaz

  • Muestra todos los objetos que existen en nuestra sesión de R.
  • Si cerramos RStudio, el entorno se borra y es justamente lo que buscamos. Lo importante es guardar el script.


rm(list = ls())   # borra todos los objetos del entorno

Proyectos de RStudio

Módulo 1 · Interfaz

Un proyecto (.Rproj) es una carpeta que reúne todo lo de un análisis. Al abrirlo, R sabe dónde estamos trabajando (el directorio de trabajo).

intro_R/
├── intro_R.Rproj
├── input/    datos originales
├── script/   código
└── output/   resultados
  • Siempre abrimos el trabajo haciendo doble clic en el .Rproj.
  • Así R sabe en qué carpeta estamos trabajando para poder buscar la base de datos y para saber dónde guardar lo que le pidamos.
  • Esto permite que el código funcione igual en cualquier computador.
getwd()   # ¿en qué carpeta estoy trabajando?

Programación básica

R como calculadora

Módulo 2 · Programación básica

10 + 5      # suma
[1] 15
10 - 5      # resta
[1] 5
10 * 5      # multiplicación
[1] 50
10 / 4      # división
[1] 2.5
2 ^ 3       # potencia
[1] 8
(5.5 + 6.2) / 2   # paréntesis primero
[1] 5.85
sqrt(16)          # raíz cuadrada
[1] 4

R respeta el orden de las operaciones: paréntesis, potencias, multiplicación y división, suma y resta.

En R los decimales se escriben con punto: 5.5, no 5,5.

Crear objetos

Módulo 2 · Programación básica

Guardamos un valor en un objeto con el operador de asignación <-:

nota_mate <- 5.5
nota_leng <- 6.2

Se lee: “nota_mate recibe el valor 5.5”. El objeto aparece en el Entorno. Para ver su contenido, escribimos su nombre:

nota_mate
[1] 5.5
promedio <- (nota_mate + nota_leng) / 2
promedio
[1] 5.85

Atajo: Alt + - escribe <- (en Mac: Option + -).

Vectores: varios valores en un objeto

Módulo 2 · Programación básica

Con la función c() (de combinar) creamos un vector: un conjunto de valores del mismo tipo.

notas_curso <- c(5.5, 6.2, 4.8, 3.9, 6.7)
notas_curso
[1] 5.5 6.2 4.8 3.9 6.7
notas_curso + 0.5   # la operación se aplica a cada elemento
[1] 6.0 6.7 5.3 4.4 7.2
length(notas_curso) # ¿cuántos valores tiene?
[1] 5

Idea clave para lo que viene: una variable de una base de datos es un vector.

Funciones

Módulo 2 · Programación básica

Una función recibe uno o más valores (argumentos), hace algo con ellos y devuelve un resultado.

nombre_funcion(argumento1 = valor1, argumento2 = valor2)

mean(notas_curso)     # promedio
[1] 5.42
median(notas_curso)   # mediana
[1] 5.5
max(notas_curso)      # máximo
[1] 6.7
round(4.8667, 1)      # redondear
[1] 4.9

Argumentos y ayuda

Módulo 2 · Programación básica

Los argumentos se pueden dar por nombre o por posición:

round(x = 4.8667, digits = 2)   # por nombre
[1] 4.87
round(4.8667, 2)                # por posición (mismo resultado)
[1] 4.87
seq(from = 1, to = 7, by = 0.5) # secuencia del 1 al 7, de 0,5 en 0,5
 [1] 1.0 1.5 2.0 2.5 3.0 3.5 4.0 4.5 5.0 5.5 6.0 6.5 7.0

Para saber qué argumentos tiene una función, pedimos ayuda:

?round        # abre la ayuda en el panel 4
help(mean)    # lo mismo

Los errores son parte del proceso

Módulo 2 · Programación básica

Nota_mate          # R distingue mayúsculas: este objeto no existe
Error: objeto 'Nota_mate' no encontrado
mean(notas_curso   # falta cerrar el paréntesis: la consola muestra "+" y espera

Lean el mensaje de error: casi siempre dice qué pasó. Los más comunes son errores de tipeo, paréntesis o comillas sin cerrar y objetos que no se han creado.

Módulo 3
Librerías (paquetes)

¿Qué es un paquete?

Módulo 3 · Librerías

  • R trae muchas funciones de base (R base): mean(), round(), c()…
  • Los paquetes (o librerías) son extensiones creadas por la comunidad que agregan funciones nuevas.
  • Se descargan desde CRAN, el repositorio oficial de R (hay más de 20.000).


Paquete Para qué sirve
readxl Abrir archivos de Excel
haven Abrir bases de SPSS, Stata y SAS
dplyr Transformar datos
ggplot2 Hacer gráficos

Instalar vs. cargar

Módulo 3 · Librerías

Instalar: una sola vez

install.packages("readxl")

Descarga el paquete al computador. El nombre va entre comillas.

Cargar: cada sesión

library(readxl)

Deja disponibles sus funciones mientras R esté abierto.


Instalar es comprar el libro. Cargar es sacarlo de la estantería.

Módulo 3 · Librerías

Una colección de paquetes diseñados para trabajar juntos en ciencia de datos. Es la base de R para Ciencia de Datos.

pacman: instalar y cargar en un paso

Módulo 3 · Librerías

Cuando usamos varios paquetes, pacman::p_load() instala los que falten y carga todos:

install.packages("pacman")   # solo la primera vez

pacman::p_load(tidyverse,   # manipulación de datos y gráficos
               readxl,      # abrir archivos de Excel
               haven)       # variables etiquetadas (SPSS, Stata)


Esta es la forma que usaremos al inicio de cada script del curso.

La notación paquete::funcion()

Módulo 3 · Librerías

Con :: podemos usar una función de un paquete sin cargarlo completo, o dejar claro de dónde viene:

readxl::read_excel("input/notas_colegio.xlsx")
dplyr::filter(notas, curso == "2°A")


¿Cuándo es útil?

  • Cuando usamos una sola función de un paquete.
  • Cuando hay conflictos (dos paquetes con funciones del mismo nombre).
  • Para que otras personas sepan de dónde viene cada función.

Variable, valor y observación

Módulo 4 · Bases de datos

id curso genero edad nota_matematicas nota_lenguaje
1 2°A Masculino 16 6.0 5.7
2 2°A Masculino 16 4.7 5.3
3 2°A Masculino 16 5.1 5.2
4 2°A Masculino 17 6.1 5.0
5 2°A Femenino 15 4.1 6.7

Variable: una característica que medimos (columna) Observación: la unidad que medimos (fila) Valor: lo que registramos (celda)

  • Una variable es una cantidad, cualidad o propiedad que se puede medir: el género, la nota en Matemáticas.
  • Un valor es el estado de una variable al medirla: la nota en Matemáticas del estudiante 2 es 4.7.
  • Una observación es un conjunto de mediciones hechas sobre la misma unidad: todo lo que sabemos del estudiante 2.

Datos ordenados (tidy data)

Módulo 4 · Bases de datos

Según R para Ciencia de Datos (cap. 12), una base está ordenada cuando cumple tres reglas:


  1. Cada variable tiene su propia columna.
  2. Cada observación tiene su propia fila.
  3. Cada valor tiene su propia celda.


Nuestra base de notas está ordenada: cada fila es un estudiante y cada columna una característica suya. Por eso se le llama base rectangular.

¿Ordenada o desordenada?

Módulo 4 · Bases de datos

Desordenada: el curso está “escondido” en los nombres de las columnas.

desordenada <- tribble(
  ~estudiante, ~mate_2A, ~mate_2B,
  "Ana",        6.1,      NA,
  "Benja",      NA,       5.4,
  "Carla",      4.9,      NA
)
desordenada
# A tibble: 3 × 3
  estudiante mate_2A mate_2B
  <chr>        <dbl>   <dbl>
1 Ana            6.1    NA  
2 Benja         NA       5.4
3 Carla          4.9    NA

Ordenada: curso es una variable con su propia columna.

ordenada <- tribble(
  ~estudiante, ~curso, ~nota_mate,
  "Ana",       "2°A",   6.1,
  "Benja",     "2°B",   5.4,
  "Carla",     "2°A",   4.9
)
ordenada
# A tibble: 3 × 3
  estudiante curso nota_mate
  <chr>      <chr>     <dbl>
1 Ana        2°A         6.1
2 Benja      2°B         5.4
3 Carla      2°A         4.9

El data frame

Módulo 4 · Bases de datos

En R, una base rectangular se guarda como un data frame: un conjunto de vectores del mismo largo, uno por columna.

estudiante <- c("Ana", "Benja", "Carla")
curso      <- c("2°A", "2°B", "2°A")
nota_mate  <- c(6.1, 5.4, 4.9)

mi_base <- data.frame(estudiante, curso, nota_mate)
mi_base
  estudiante curso nota_mate
1        Ana   2°A       6.1
2      Benja   2°B       5.4
3      Carla   2°A       4.9

Cada columna es un vector (Módulo 2). Todas deben tener la misma cantidad de valores: uno por observación.

Tibbles: data frames modernos

Módulo 4 · Bases de datos

El tidyverse usa tibbles (cap. 10): data frames que se imprimen de forma más ordenada.

tibble(
  estudiante = c("Ana", "Benja", "Carla"),
  curso      = c("2°A", "2°B", "2°A"),
  nota_mate  = c(6.1, 5.4, 4.9)
)
# A tibble: 3 × 3
  estudiante curso nota_mate
  <chr>      <chr>     <dbl>
1 Ana        2°A         6.1
2 Benja      2°B         5.4
3 Carla      2°A         4.9

Al imprimir un tibble vemos:

  • El número de filas y columnas (3 x 3).
  • El tipo de cada variable bajo su nombre: <chr> texto, <dbl> número.
  • Solo las primeras 10 filas (no inunda la consola).
as_tibble(mi_base)   # convierte un data frame en tibble

Variables numéricas

Módulo 5 · Variables

Con ellas podemos hacer operaciones matemáticas: sumar, promediar, calcular desviaciones.

summary(notas$edad)
   Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
  15.00   16.00   16.00   15.96   16.00   17.00


Cuidado: que una variable esté guardada como número no significa que sea cuantitativa. Si genero estuviera codificada como 1 = Femenino y 2 = Masculino, su “promedio” (por ejemplo, 1,5) no tendría ningún sentido. Siempre hay que revisar el libro de códigos.

Variables de texto (character)

Módulo 5 · Variables

Guardan texto, siempre entre comillas. No se pueden promediar, pero sí contar:

head(notas$genero)
[1] "Masculino" "Masculino" "Masculino" "Masculino" "Femenino"  "Femenino" 
table(notas$genero)

 Femenino Masculino 
       49        49

Para R, "Femenino", "femenino" y "FEMENINO" son tres valores distintos. Esto es frecuente en respuestas abiertas o bases mal digitadas.

Variables lógicas

Módulo 5 · Variables

Solo toman los valores TRUE (verdadero) o FALSE (falso). Aparecen cuando hacemos comparaciones:

Operador Significa
== igual a
!= distinto de
>, >= mayor (o igual)
<, <= menor (o igual) 
5.5 >= 4
[1] TRUE
"2°A" == "2°B"
[1] FALSE
head(notas$nota_lenguaje >= 4)
[1] TRUE TRUE TRUE TRUE TRUE TRUE

Se usan muchísimo para filtrar casos (módulo 6). Además, TRUE vale 1 y FALSE vale 0, por lo que mean() de un vector lógico da una proporción.

Factores: variables categóricas

Módulo 5 · Variables

Un factor es una variable categórica con un conjunto fijo de niveles (levels) (cap. 15).

genero_f <- factor(notas$genero)
levels(genero_f)
[1] "Femenino"  "Masculino"

Los factores permiten definir un orden que no sea el alfabético, útil para variables ordinales:

nivel <- c("Medio", "Bajo", "Alto", "Medio")
factor(nivel)                                          # orden alfabético
[1] Medio Bajo  Alto  Medio
Levels: Alto Bajo Medio
factor(nivel, levels = c("Bajo", "Medio", "Alto"))     # orden con sentido
[1] Medio Bajo  Alto  Medio
Levels: Bajo Medio Alto

Valores perdidos: NA

Módulo 5 · Variables

En R, un dato faltante se representa con NA (Not Available). Es “contagioso”: cualquier operación con un NA da NA.

notas_ejemplo <- c(5.5, NA, 6.1, 4.8)
mean(notas_ejemplo)
[1] NA
mean(notas_ejemplo, na.rm = TRUE)   # na.rm = TRUE: ignora los NA
[1] 5.466667
is.na(notas_ejemplo)                # ¿qué valores son NA?
[1] FALSE  TRUE FALSE FALSE

Un NA no es un cero: significa “no sabemos” cuál es el valor.

El problema de los códigos 888 y 999

Módulo 5 · Variables

En nuestra base, los datos perdidos no están como NA, sino como 888 (No rindió) y 999 (Sin información). ¿Qué pasa si calculamos el promedio directamente?

mean(notas$nota_matematicas)
[1] 33.38163
mean(notas$nota_lenguaje)
[1] 33.5051

Un promedio de 33 en una escala del 1 al 7. Esto pasa porque para R, 888 y 999 son números como cualquier otro. Antes de analizar, hay que recodificarlos a NA (lo haremos en el módulo 6).

table(notas$nota_matematicas %in% c(888, 999))   # ¿cuántos casos tienen esos códigos?

FALSE  TRUE 
   95     3

Variables etiquetadas: haven_labelled

Módulo 5 · Variables

Las bases de SPSS y Stata guardan etiquetas: un texto asociado a cada código. Al importarlas con haven, R las lee como haven_labelled.

nota_etiq <- labelled(c(5.5, 6.1, 888, 4.2, 999),
                      labels = c("No rindió" = 888, "Sin información" = 999))
nota_etiq
<labelled<double>[5]>
[1]   5.5   6.1 888.0   4.2 999.0

Labels:
 value           label
   888       No rindió
   999 Sin información

Es lo que veríamos si nuestra base de notas viniera en formato .sav. En la CASEN aparecen así casi todas las variables.

as_factor(nota_etiq)
[1] 5.5             6.1             No rindió       4.2            
[5] Sin información
Levels: 4.2 5.5 6.1 No rindió Sin información

Regla práctica: zap_labels() para variables que vamos a promediar; as_factor() para variables categóricas que vamos a contar o comparar.

Cambiar el tipo de una variable (coerción)

Módulo 5 · Variables

Las funciones as.*() transforman un tipo en otro:

as.numeric("5.5")             # texto a número
[1] 5.5
as.character(16)              # número a texto
[1] "16"
as.numeric(c("6.1", "seis"))  # lo que no es número se vuelve NA
[1] 6.1  NA

Cuidado con as.numeric() sobre un factor: devuelve el número del nivel, no el valor original.

edades_f <- factor(c("17", "15", "16"))
as.numeric(edades_f)                  # ✘ posiciones de los niveles
[1] 3 1 2
as.numeric(as.character(edades_f))    # ✔ valores originales
[1] 17 15 16

Transformar datos con dplyr

La lógica de dplyr

Módulo 6 · dplyr

dplyr (parte del tidyverse) ofrece verbos para transformar datos (cap. 5). Todos funcionan igual:

  1. El primer argumento es una base de datos.
  2. Los siguientes argumentos dicen qué hacer, usando los nombres de las variables sin comillas y sin $.
  3. El resultado es una nueva base de datos.
Verbo Qué hace
filter() Elige filas según una condición
arrange() Ordena las filas
select() Elige columnas
rename() Cambia nombres de columnas
mutate() Crea o modifica variables
group_by() + summarise() Resume por grupos

El pipe: %>%

Módulo 6 · dplyr

El pipe toma lo que está a su izquierda y lo pasa como primer argumento de la función de la derecha. Se lee “y luego”.

Sin pipe: se lee de adentro hacia afuera

round(mean(c(5.5, 6.2, 4.8)), 1)
[1] 5.5

Con pipe: se lee de izquierda a derecha

c(5.5, 6.2, 4.8) %>%
  mean() %>%
  round(1)
[1] 5.5


Atajo: Ctrl + Shift + M escribe %>%. También existe el pipe nativo de R, |>, que funciona igual en casi todos los casos.

mutate(): recodificar 888 y 999 a NA

Módulo 6 · dplyr

mutate() crea o modifica variables. Con if_else() reemplazamos los códigos por NA:

notas <- notas %>%
  mutate(nota_matematicas = if_else(nota_matematicas %in% c(888, 999), NA, nota_matematicas),
         nota_lenguaje    = if_else(nota_lenguaje    %in% c(888, 999), NA, nota_lenguaje))

summary(notas$nota_matematicas)
   Min. 1st Qu.  Median    Mean 3rd Qu.    Max.    NA's 
  3.300   4.700   5.100   5.225   5.800   7.000       3

if_else(condición, valor si es verdadero, valor si es falso). Ahora el máximo es 7 y aparecen los NA's.

Esta vez sí guardamos el resultado con notas <-: la base queda corregida para lo que sigue.

mutate() con case_when()

Módulo 6 · dplyr

Para recodificar en más de dos categorías, usamos case_when(): cada línea es condición ~ valor.

notas <- notas %>%
  mutate(tramo_lenguaje = case_when(nota_lenguaje <  4   ~ "Insuficiente",
                                    nota_lenguaje <  5.5 ~ "Suficiente",
                                    nota_lenguaje >= 5.5 ~ "Destacado",
                                    TRUE ~ NA_character_)) # Dependiendo de la naturaleza de la variable ponemos NA_real_, NA_complex_, NA_integer_

table(notas$tramo_lenguaje, useNA = "ifany")

   Destacado Insuficiente   Suficiente         <NA> 
          46            6           43            3

Las condiciones se evalúan en orden: un 4,8 no cumple la primera, sí la segunda, y ahí se queda. Los NA siguen siendo NA.

summarise(): resumir

Módulo 6 · dplyr

summarise() reduce toda la base a una fila con los estadísticos que pidamos:

notas %>%
  summarise(n          = n(),
            media_mate = mean(nota_matematicas, na.rm = TRUE),
            media_leng = mean(nota_lenguaje, na.rm = TRUE),
            de_leng    = sd(nota_lenguaje, na.rm = TRUE))
# A tibble: 1 × 4
      n media_mate media_leng de_leng
  <int>      <dbl>      <dbl>   <dbl>
1    98       5.23       5.35   0.900

Ahora que recodificamos los 888 y 999, los promedios sí tienen sentido. Y no olvidar na.rm = TRUE.

Módulo 6 · dplyr

¿Las brechas de género en las notas son iguales en ambos cursos?

brechas <- notas %>%
  filter(!is.na(nota_matematicas), !is.na(nota_lenguaje)) %>%   # solo casos válidos
  group_by(curso, genero) %>%                                   # por curso y género
  summarise(n = n(),
            mate = mean(nota_matematicas),
            leng = mean(nota_lenguaje),
            .groups = "drop") %>%
  mutate(diferencia = round(mate - leng, 2)) %>%                # mate - lenguaje
